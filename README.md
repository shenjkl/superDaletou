# 大乐透研究台

个人使用的大乐透方法研究工作台，重点是比较方案成本、收益分布及证据；不提供购票或收益保证。当前正式首版仍在实施，已完成和待完成范围见 [实施计划](IMPLEMENTATION_PLAN.md)。

## 本机运行

需要 Python 3.12 和 [requirements.txt](requirements.txt) 中的 NumPy、pypdfium2 与 Pillow。已验证环境为 Windows、Python 3.12.14、NumPy 2.3.5、pypdfium2 5.14.0 和 Pillow 12.3.0；使用其他环境前请先安装并验证依赖。PDF 查看在独立限额进程中逐页生成图像；相关许可证及 PDFium 依赖见 [pypdfium2 项目说明](https://github.com/pypdfium2-team/pypdfium2)。项目不包含 Python 运行时。

在项目目录安装依赖：

```powershell
python -m pip install -r requirements.txt
```

在项目目录启动本机浏览器服务：

```powershell
python -m dlt.app --db runtime/research.sqlite3 --port 8766
```

Web 服务与独立计划命令启动时都会核验数据库目录、数据库文件和 SQLite 日志文件的本机访问权限；新建数据库目录会按当前账户限制访问，不安全的既有路径会被拒绝。详见[本机服务数据访问保护](docs/local_access_protection.md)。

浏览器访问 `http://127.0.0.1:8766/`。训练页可载入工作区已有的历史研究快照，配置并提交树模型或 LSTM 训练；历史快照不代表本次实时联网核验。训练完成后可从任务进入方案生成，或在生成页选择可用产物，生成并保存候选和同成本、同结构随机对照，并用固定历史奖金或用户自定义奖金情景评估具体子注。刷新后可恢复草稿及评估。目标期、日期和价格目前由使用者输入，属于未核验的研究情景，不是前瞻登记或购买建议。模型尚需独立回测，模型评分不是中奖概率。以文件方式直接打开原型时无法执行真实训练或保存这些后端草稿。

已保存的组合草稿可下载经过白名单处理的生成重放包；模型方案可选择独立重训并比对权重。验证方式与不包含的内容见 [生成重放说明](docs/generation_replay.md)。这不是完整研究备份或来源真实性证明。

已计算的本人留存纸面实验可下载单期结算重放包，在本机离线复核组合金额与配对差额。字段、隐私边界和验证命令见[纸面结算重放说明](docs/paper_replay.md)；该文件不能恢复完整数据库。

本机服务运行时会在后台检查已启用的开奖更新计划；浏览器关闭后服务继续运行。计划默认暂停，配置、启停及可选的独立更新进程见 [后台更新说明](docs/background_updates.md)。提供默认关闭的 Windows 登录后启动设置；此能力尚未完成真实注销或重启验证。关闭本机服务、关机或休眠时不会继续检查。

“数据与规则”页面可对本机数据库执行只读的部分完整性检查，也可生成并下载口令加密的数据库快照；[数据完整性说明](docs/data_integrity.md)和[加密快照说明](docs/encrypted_backup.md)列出检查范围及敏感资料边界。页面还支持口令认证与内存检查、创建隔离候选、复核候选，以及把候选激活为新路径的数据库副本。恢复文件操作会先在浏览器保存不含口令的待确认记录；口令仅用于当前提交。当前检查只是部分结构和业务检查，不会自动切换服务配置，也未完成完整业务、真实浏览器及重启恢复验收。

可通过命令行或页面准备仅供本机检查的隔离恢复候选副本，并在复核后显式激活为新路径副本。激活不会切换默认库；经确认后可用 `python -m dlt.app --db <恢复副本路径>` 明确启动。候选、激活和启动的限制及敏感数据提示见 [隔离恢复说明](docs/recovery_staging.md)；这不是脱敏备份或完整恢复验收，旧版程序和直接修改数据库不受隔离标记保护。

“历史回测”页面可核对候选奖期的本机使用记录，并在未发现使用且用户确认后固定为探索排除范围；新的训练、生成和探索回测会检查这些奖期。页面或外部工具仍可能访问数据，该功能不证明奖期独立或本人未看到结果。检查范围及限制见 [范围核对说明](docs/holdout_audit.md)。

已固定但从未运行的历史评估若因系统升级无法启动，可以经本人确认和本机复核创建关联新版本；新版本保留原方法、范围、种子及奖金情景，旧版保留但不能再运行。已运行过的协议不适用此流程。

前瞻实验和历史评估可查看已观察的税后配对差额分布及逐期移除敏感性；这不是置信区间或采用建议，计算口径见 [配对差额说明](docs/paired_description.md)。

“证据结论”页面可对多奖期实验或固定历史评估记录个人判断及理由，保存当时的证据快照，并从判断提出新假设草稿。在“前瞻实验”新建实验版本时可选择草稿；新实验仍需单独核验资料和截止时间。旧证据变化会提示复核，不会覆盖原判断；保存“结束假设”不会自动关闭实验版本。该流程不涉及真实购买，也不证明策略有效。

固定范围后，可一次性固定多个方法和统一评估协议，随后运行历史描述评估并查看逐期与副本结果；失败时可显式按原协议重试，保留各次运行记录。来源发生冲突时结果转为待复核。此流程不证明盲测、历史时点可用或方法优势，也不启用假设检验和购买结论。

官方规则、税费和日历的查阅记录见 [规则来源核对](docs/official_source_review.md)；链接仅为人工核对入口，不代表目标期已自动核验。

纸面结算要求规则及税费资料显式声明支持的计税单位，并假设每个替代方案没有其他同一期同游戏的中奖收入；旧资料缺少计税单位时，相关旧结果会保留并标为待复核，不能直接作为当前有效收益。资料补充和更正方式见[前瞻登记说明](docs/prospective_registration.md)。

## 当前范围

- 已接入页面：训练任务、模型产物驱动的候选与随机对照、草稿回看及固定历史情景下的实际包评估、可取消的描述性历史滚动回测、更新计划的创建与启停，以及本人核对资料后的单奖期登记、固定协议下的多奖期逐期登记和成本收益描述汇总。多奖期版本支持固定模型，或固定训练规则后手动重训；逐期重训还可由用户逐期明确创建后台训练计划，生成配对和登记仍须手动完成。具体口径见 [组合评估说明](docs/portfolio_evaluation.md)、[历史回测说明](docs/historical_backtest.md)、[前瞻登记说明](docs/prospective_registration.md) 和 [后台更新说明](docs/background_updates.md)。仅本机监听，写请求需要本机会话与来源校验。
- 尚未完成：官方规则适用核验及正式规则自动结算、独立保留集与统计推断、Windows 登录后启动的真实验收和全量验收。PRD v0.7 要求并排比较固定情景，不定义跨情景加权汇总的权重、统计对象或解释；该汇总不属于当前 PRD 验收范围。组合研究评估已支持用户自定义 18 种命中结果的奖级映射、奖金金额和税费参数；这些仅是研究假设，不构成已核验的自定义正式规则，也不用于正式结算或前瞻有效收益。各类方法可为每期另行确认自动生成和登记计划；开奖数据版本及日历、规则、税费资料更正支持本人查看差异、重算和追溯旧结果。规则及税费可选择所有引用期或单独指定一期，日历更正限定同一期，不自动发现或核验官方原文。针对缺少本地合格观察的已登记历史期，后台支持受页数上限约束的跨页查询；真实跨页接口尚未验收。2026-10-30 在沙箱外的临时数据库成功验证了官方接口单页抓取及后台保存；受限沙箱内的直接联网仍可能失败。
- 已封存的 `research/prospective/v2` 仅用于只读查验；运行数据写入另行指定的 SQLite 数据库。

测试：`python -m unittest discover -s tests`。正式使用前应完成当前实施计划列出的各阶段验收。
