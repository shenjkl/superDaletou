# 大乐透研究台页面

八页网页已接入本机研究服务，涵盖训练、候选生成、历史回测、前瞻实验、证据查看及数据管理。功能接入不代表目标环境端到端验收完成。项目运行和正式首版进度见 [项目说明](../README.md) 与 [实施计划](../IMPLEMENTATION_PLAN.md)。

## 打开方式

在项目目录启动 `python -m dlt.app --db runtime/research.sqlite3 --port 8766`，通过 `http://127.0.0.1:8766/` 打开。训练页可显式载入工作区历史快照、提交真实树模型和 LSTM 训练、取消任务并在刷新后查看记录；生成页可使用可用产物生成并保存候选与同结构随机对照。目标期和价格为人工情景，未经官方核验；模型产物不代表方法有效。训练需要 Python 与 NumPy，任务由受限的本机子进程执行。

直接打开 `index.html` 仍可查看静态页面及浏览器内计算，但不会连接本机 API，也不会执行真实训练、持久任务或前瞻结算。服务连接时，数据页可管理更新计划；后台更新进程由本机服务协调，细节见 [后台更新说明](../docs/background_updates.md)。

## 页面边界

- 方案比较仍使用历史固定奖金情景和浏览器计算；不重算假设新增中奖者分奖及限额。
- 服务连接时，方案生成使用后端随机、热号、冷号、树模型或 LSTM 方法，保存候选、同结构随机对照及完整号码包；可执行包级评估。直接打开文件时保留有限的浏览器内随机/热号/冷号逻辑。
- 历史回测页连接持久任务、报告、排除范围核对和固定历史评估；前瞻页连接固定实验/系列、逐期登记、来源核验、纸面结算与更正；证据页连接研究记录及判断/假设草稿。
- 数据页接入快照、来源冲突、更新计划及备份恢复的部分流程。加密备份恢复只提供候选检查和新路径激活等已实现能力，不代表完整数据库恢复验收通过。
- 既有第 26124 期封存研究记录只读展示，不能当作本产品已完成的新实验或新结算。
- 标注的历史研究基线截至 2026-10-29；载入工作区快照不等于本次联网核验。真实官方联网、目标 Windows 环境部署、真实浏览器/HTTP、断连及重启恢复仍须按实施计划逐项验收。

本目录的旧检查脚本保留为历史原型验证资料，其中训练流程预期已被真实训练流程替代，不能作为当前服务的验收证据。
