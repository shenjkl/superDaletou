# 大乐透研究台：原型范围与交互约束

更新日期：2026-11-04。产品定位见 [PRODUCT.md](../PRODUCT.md)，正式首版范围及验收见 [PROJECT_SCOPE.md](../PROJECT_SCOPE.md)。本文件描述当前代码能力；正式首版仍以实施计划中的验收证据为准。

## 1. 目标与交付

用户个人使用；首版定位包含多模型研究。当前代码包含本机网页与回环服务、持久研究记录、真实树/LSTM训练、候选与对照、历史回测、前瞻登记和纸面结算等流程。功能已接入不等于本地部署、浏览器、网络来源、重启恢复或正式首版验收已通过。

## 2. 八个页面

| 页面 | 当前可评审内容 |
|---|---|
| 研究概览 | 更新/研究状态、研究日程、证据边界和下一步入口 |
| 方案比较 | 预算、结构、追加、成本余额、显式重算和合并概率明细表 |
| 模型训练 | 方法说明行内展开，训练配置页内编辑、期号校验和任务状态 |
| 方案生成 | 随机、热号、冷号、树模型及 LSTM；单式、复式和固定胆拖；候选与同结构对照、草稿及包级评估 |
| 历史回测 | 持久回测任务与报告、探索范围核对和固定历史描述评估 |
| 前瞻实验 | 固定单期/多期方案、逐期候选登记、来源核对、开奖复核、纸面结算及更正 |
| 证据结论 | 历史与前瞻证据、配对说明、个人判断及关联的新假设草稿 |
| 数据与规则 | 官方快照、来源冲突、规则/日历/税费版本、更新计划、备份与部分恢复工具 |

## 3. 当前实现边界

- 概率计算：给定第26123期公布单注奖金情景；复式、固定胆拖和重复投注精确计数，分散单式采用固定种子模拟。理论平均奖金按组合概率计算；不重算新增假设中奖者的分奖和限额。
- 生成计算：读取200期已核验官方历史，按60/120期窗口产生具体号码，保留参数、历史摘要和种子。预算2—360元，目标期当前为快照后下一期26124；这些是原型限制，非永久产品规则。
- 随机对照：同实际成本、同结构、独立种子；同目标开奖的两组组合包不视为两个独立奖期。
- 模型：训练服务可在本机子进程中训练真实树模型/LSTM并保存版本化产物；历史回测也可逐期重训。模型评分未经概率校准，独立保留集和独立评分流程尚未接入。
- 回测与包级评估：已接入持久回测任务、逐期配对报告、具体候选/对照号码包结算和固定范围后的历史描述评估。探索回测只接受 `exploration` 角色；范围排除不能证明数据未被研究者或外部工具看过。
- 草稿：手动定义和携带生成结果的草稿分别保留来源；生成草稿保存具体候选/对照全部号码，不套用其他副本设置。前瞻协议、逐期登记和结果使用独立持久记录。
- 持久化与恢复：本机 SQLite 保存任务、计划和研究记录；待确认写入在浏览器 IndexedDB 留存请求并提供状态核对/封止/关联重试。加密备份、候选复核和新路径激活已有部分实现；数据库连续性、真实浏览器/HTTP/重启和 ACL 验收仍未完成。
- 证据：已有历史研究基线和封存研究记录按原来源展示；新运行记录须与旧成果区分。系统不将副本波动、训练完成或历史回测自动表述为方法有效或未来盈利。

## 4. 交互与呈现

Operate模式，面向Windows桌面的反复研究操作，兼顾手机。沿用浅灰蓝工作面、白色容器、深蓝文字和钴蓝操作；系统中文字体、数字对齐，状态同时显示文字。

- 短方法说明在原行展开，配置在页面内编辑，草稿按定义、对照、复核三步呈现；取消返回入口，步骤返回保留输入。
- 模型训练、生成和研究证据分别显示状态；常规按钮、表单、任务和提示使用产品用语，能力范围集中在使用说明。
- 概率条和明细合并为一表，每方案一行；“理论平均奖金（税前）”悬停提示为“包含未中奖及罕见大奖”。
- 重新计算入口与模拟次数集中在结果标题区；旧参数结果失效后隐藏，不放大旧结果冒充重算。
- 生成参数变化后候选失效，不能继续按新参数登记旧号码；草稿登记不重新抽取组合。
- 手机表单转单列，表格内部横向滚动，号码列表可展开，整个页面不得横向撑宽。
- 保留可见键盘焦点，取消/Escape收起配置；只读摘要可使用现有记录查看面板。

## 5. 原型验收

检查八页导航、桌面/手机、键盘、输入错误、空状态、运行/停止/完成、结果失效与重新生成；核对数值和随机种子重放、候选合法去重、对照成本与结构、草稿号码回看及封存资料只读。

当前页面和服务代码接入不代表上述流程已在目标 Windows 环境完成真实服务、浏览器、网络、故障注入和重启验收。逐项状态见 [正式首版实施计划](../IMPLEMENTATION_PLAN.md)。
