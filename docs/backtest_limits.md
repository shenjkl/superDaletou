# 历史回测与固定评估限额

`dlt/backtest_limits.py` 中的不可变 `DEFAULT_BACKTEST_LIMITS` 是历史回测核心校验、后台任务及固定评估共用的当前默认配置：

| 项目 | 当前范围 |
|---|---:|
| 目标奖期数 | 最多 50 期 |
| 副本数 | 最多 10 个 |
| 目标期 × 副本总量 | 最多 100 组 |
| 历史窗口 | 12–200 期 |
| 单次执行时限 | 1–120 秒 |
| 单方案子注 | 最多 100 注 |
| 抽样尝试 | 最多 20,000 次 |
| 单方案预算 | 200–20,000 分 |
| 模型验证长度 | 1–100 期 |

核心协议会在记录研究使用和计算前执行目标数、组合成本、结构、模型参数与版本校验；任务入口另外检查超时。数值为原型默认配置，尚未依据目标硬件完成性能标定。

`/api/training-limits` 同时返回 `backtest` 对象，前端统一限额解析器会校验其必需字段及范围。历史回测与固定评估表单据此设置输入边界、候选资源上限及协议 `limits`；配置缺失或无效时，不显示可提交的回测表单。服务端核心校验仍是最终约束。
