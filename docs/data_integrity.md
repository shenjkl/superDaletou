# 本机数据完整性检查

本机服务启动后，在“数据与规则”选择“检查数据完整性”。检查使用 SQLite 只读连接和同一读取事务，不修改、修复、备份或恢复数据库。结果反映检查时的快照；检查结束后数据库仍可能被其他正常任务更新。

检查包括 SQLite 自身完整性和外键，以及已实现的开奖快照、来源原文、模型产物、方案配对、评估、回测报告、本人核对资料、固定实验、规则和税费更正、纸面结果及当前结果发布链的摘要、引用和部分业务计算合同。每条已保存纸面结果会使用对应固定实验、开奖行和当时引用的规则重新计算各包奖金、税费、成本、派奖拆分及候选/对照差额；同时核对其来源观察原始字节、快照摘要和开奖行，并要求观察时间不早于登记及截止、且不晚于首次发布。纸面结算事件若标记为完成，还须指向同一实验、同一来源快照的有效结果组。计算或来源关联不一致时，隔离候选不能通过检查。官方域名格式和本地时间不构成独立来源或时间认证。界面只显示问题所属类别与记录序号，不回显文件内容、用户输入或本机路径。

开奖原文解析要求号码字段包含恰好 7 个 ASCII 十进制 token，每个 1—2 位，并继续核对区间、重复值和期号。自动更新已收到但未通过开奖格式或页范围核验的响应会以原始字节、摘要、来源、接收时间和原因追加保存到 `source_quarantine`；它不会进入可研究快照，也不会覆盖旧快照。数据页只显示最近 50 条记录的摘要；经本机会话核验后，用户可将原文按 `application/octet-stream` 附件下载，服务端先重核摘要，不在浏览器内联渲染。隔离原文仍可能含非预期敏感内容，会包含在本机数据库及数据库备份中；该记录目前只覆盖自动开奖抓取链路，网络错误、非成功 HTTP 状态及其他导入入口不生成此类隔离记录。

实际组合评估会进一步核对固定请求、结果摘要、组合摘要、模拟次数和种子、情景说明、票价及来源引用；自定义奖金会按留存输入重新构造假设。检查还依据完整子注和所保存的奖级金额独立重算理论平均税前奖金与一等奖号码覆盖，检查保存的值是否一致。历史奖金来源出现新版本冲突时，旧记录可以完整保留，当前评估资格仍由业务复核决定；完整性通过不表示该评估可作为当前结果。检查不重放随机模拟样本，也不能证明整条请求和结果未被一起伪造、真实来源已经认证或数据满足独立性要求。

旧自定义奖金来源声明以追加记录保存；检查会核对声明摘要、原评估和情景引用、声明内容及不可修改触发器。核对通过只说明记录之间一致，不能验证本人声明为真，也不消除任何已记录的历史来源风险。

固定排除范围预留会核对提交请求与原始范围记录的快照、起止奖期、摘要和保存结果；封止记录不能与同请求的已接受结果并存，关联重试必须指向同内容封止并且最多只有一个直接后继。检查也核对相关表的外键、唯一约束、不可修改触发器及提交/封止冲突触发器。通过仅说明本机日志与范围记录相互一致，不证明用户或外部工具未看过这些开奖，也不阻止旧版服务、直接数据库写入或数据库回滚绕过当前协议。

固定实验检查同时核对原始固定请求与实验协议、协议副本清单与留存配对的顺序和对应关系、重复副本及种子、配对引用，以及配对的目标期和日历/规则版本。即使记录内容被修改后重新计算了摘要，仍可发现这些合同不一致；该检查不能证明记录未被整体替换，也不重新认证资料来源或本机时间。

更新计划的已留存配置变更会核对前后摘要、变更链与当前配置；已留存的运行配置快照核对摘要和参数合法性。较早运行可能没有配置快照，页面会标明未留存，完整性检查不会补造历史参数；这不是对所有旧运行配置的证明。

同一合同用于实验状态检查、纸面收益计算和当前结果读取；发现不一致时停止发布或隐藏当前结果，并保留原记录供核对。历史记录的读取入口仍可查看已留存内容，不表示其当前有效。

对逐期自动训练计划，检查固定请求与日历、实验版本的关联，状态事件的允许顺序、重试序号和当前状态一致性；对已提交任务，核对固定历史窗口摘要、训练配置、任务和已完成模型产物的关联，并检查曾运行的旧任务仍可追溯。后续出现相互冲突的来源不会改写当时固定的历史摘要；来源是否需要业务复核仍由使用该数据的流程判断。该检查不覆盖所有计划与运行记录的业务合同。

纸面结果若包含日历更正引用，检查其原日历、所用日历及已留存更正链是否一致；历史上不含该字段的结果保留旧格式，不会伪造一条更正链。

规则和税费结果若包含更正链，会按结果所属奖期核对每条全局或按期更正记录及链的起止资料；全局和按期更正均须有对应的持久任务记录。检查未覆盖所有业务合同，也不能证明留存材料来自官方。

逐期自动登记计划检查固定请求摘要、关联的训练计划、状态事件及完成后对应的固定实验；同时检查同一训练计划最多一个等待中或已完成登记计划的数据库约束。该检查不认证来源、时间，也不能取代完整恢复验收。

固定模型和无需训练方法的自动登记计划另行检查请求、所选快照与历史窗口摘要、状态事件及对应固定实验；后来发现的来源冲突仍由业务状态标记待复核，不把历史记录误报为摘要损坏。

未运行固定评估的关联新版本会检查前序范围、协议摘要、无运行尝试、无分叉或环，以及除执行环境和版本引用外的协议内容保持一致。SQLite 一致副本中的版本链也可进行这些检查；这不等于完成全部恢复或来源真实性验收。

固定历史评估写入日志会核对操作和规范化请求摘要、接受回执与对应固定协议/运行尝试/金额更正/关联范围的引用，封止请求不能与同键接受回执并存，关联重试必须指向同操作、同内容封止且最多只有一个直接后继。相关表的主键、外键、唯一约束和迟到启动触发器也纳入检查。来源复核/更正和恢复文件操作的接受、封止与关联重试账本也会检查规范请求摘要、对象键、业务回执关联、时间戳及重试链；候选/恢复数据库中的恢复写入回执检查操作类型、请求标识、摘要和时间戳。通过只表示本机日志与记录结构一致，不证明浏览器断连恢复、请求未被整体伪造或任务后台已完成。

结构检查还会核对已知表的必需字段集合及这些必需字段的 SQLite 声明类型、非空要求和默认值（包含预期无默认值的字段）、主键、外键列/目标及有歧义表的外键分组、28 个唯一约束、9 张表的 12 个已声明 CHECK 表达式、两个部分唯一显式索引，以及不可修改记录的触发器和资料更正入队触发器的预期定义。外键分组检查可区分分别引用同一来源表的旧/新资料字段，也可识别必须保持为一个复合引用的研究写入键；若合同清单中的多个字段指向同一目标却缺少分组合同，检查本身会失败，避免新增表时静默遗漏这一约束。列与 CHECK/UNIQUE 合同从 `dlt/*.py` 中已识别表的字面建表语句提取；额外字段允许保留。必需字段缺失、类型、空值或默认值合同不符、必需 CHECK/UNIQUE/显式索引缺失或改变、保护触发器缺失或被同名空操作替换会导致检查失败；未识别的表、触发器或显式索引会使检查标记为不完整。回测与训练任务还会按任务状态核对结束时间、错误字段和产物/不可变报告；成功训练必须关联配置及历史区间一致的模型产物，完成回测必须关联协议及场景一致的报告。全部业务关系、应用行为或恶意篡改仍不在完整验证范围内。

个人判断与新假设草稿会核对记录摘要、请求与证据快照、草稿对原判断的关联，以及新实验引用草稿时的假设一致性。检查不证明判断正确、来源真实或记录没有被拥有数据库写权限的人整体替换。

配对检查核对请求、历史窗口摘要、双方种子、号码结构、追加、注数和成本；生成代码与 Python 版本匹配时重放随机对照及随机/热号/冷号候选。模型代码、Python 和 NumPy 版本也匹配时，检查模型结构、训练输入摘要、训练与验证目标及排除边界，并用留存权重重算评分及候选号码；不在此处重新训练。独立保存的模型产物也检查上述训练输入与目标。版本不匹配时不声称重放通过；此检查不会自动证明旧代码的行为。历史回测中可重新运行版本校验的完整配对也按同一规则检查。检查固定快照自身时不把后来导入的冲突观察视为原始记录损坏；正常使用模型或配对仍会因未解决冲突转为待复核。

“已检查项目未发现异常”只表示**已实现且实际执行的检查**没有发现问题。它不表示全部业务关系已验证，也不证明来源真实、时间可信、研究有效、文件不含敏感内容，或数据库可以安全恢复。遇到未知表、未知触发器或旧来源未留原文字节时显示“检查不完整”；摘要、关联或数据库结构异常时显示“发现需要处理的问题”。

命令行也可手动检查指定的本机数据库：

```powershell
python -m dlt.integrity runtime/research.sqlite3
```

命令输出 JSON；检查通过退出码为 0，失败或检查不完整退出码为 2。不要把输出用于替代备份。应用已有口令加密的一致性数据库快照、受保护的隔离候选、候选复核及恢复到新路径的部分页面/命令流程；恢复失败时保留原库和候选。当前完整性检查遇到未知表、未知触发器或其他未覆盖项目会标记“不完整”并阻止候选发布/激活。该检查只覆盖已实现合同，尚未证明恢复后完整业务行为、后台启动兼容、真实浏览器/服务重启和目标机访问策略，不能据此称为完整恢复验收通过。

前瞻关闭写入日志会检查操作类型、规范化请求摘要、接受结果与单期/系列关闭行的一致性、封止与接受互斥、关联重试指向同内容封止请求且每个封止最多一个直接后继。相关主键、外键、唯一约束、不可变触发器及封止/关闭竞争触发器也纳入检查。此项通过只说明本机日志和关闭记录结构一致，不证明浏览器已成功恢复，也不保护旧版服务或直接数据库写入。

模型选择决策以单独的不可变序列保存。结构检查核对草稿外键、序号前驱、每个草稿最多一个序号及请求键、摘要、训练尝试引用与待确认写入回执；更早格式的选择在首次载入时作为首条历史保留。该合同保证本机记录链条一致，不证明本人披露完整，也不认证模型选择的独立性。
