# 纸面结算重放包

在“前瞻实验”的本机已固定实验列表中，当前纸面结果为“本人留存”时可下载结算重放包。生成时系统在同一数据库读取快照内检查当前结果、固定配对、规则、开奖原始观察与来源冲突，并重新核算每份候选和对照；结果不一致、原始观察缺失或待复核时拒绝导出。用户界面状态可能在点击后变化，以服务器重新检查的结果为准。

文件包含一个奖期当前结果所需的开奖数字、完整子注、票价、匿名化奖级映射、奖金金额、税费参数、逐副本的重算金额及平均配对差额。系统通过固定字段白名单构造文件：不复制用户自由文本、原始来源文件、来源网址、会话令牌或本机路径。原有奖级名称被替换为内部编号；文件还包含实验、结果、快照及程序摘要，以便关联和核对。**号码、金额和摘要仍是个人研究资料，应由本人决定保存和分享方式。**

在项目目录中，使用 Python 运行：

```powershell
python -m dlt.paper_replay "下载的重放包.json"
```

`status: matched` 表示该文件的摘要和其中逐包奖金、税、成本、净收益及配对差额可由当前结算代码重算一致；退出码为 0。结构、摘要或金额不符时退出码为 2。`calculator_matches_export` 表示当前 `settlement.py` 的摘要是否与导出时一致；即使数值一致，值为 `false` 也表示使用的代码版本不同。原结果记录的是结算工作流代码摘要，旧记录并未单独固定当时的 `settlement.py` 摘要，不能以导出时摘要冒充当时的版本。

新导出的 v2 重放包明确包含计税单位；`tax_unit_evidence: explicit_bundle_assumption` 表示包中声明了计算假设，不是官方认证。旧 v1 包可按其原本隐含的整包计税算法重算，结果标记 `legacy_implicit_calculation_only`；此兼容仅用于核对历史算术，不能证明旧资料已核验计税单位，也不能将待复核的旧结果当作当前有效结果。

重放包限定最多 100 个副本、合计 10,000 条子注和 4 MiB，超限时拒绝导出。只导出当前有效的单奖期结果，不包含历史结果版本、完整研究数据库、模型训练过程、本人核对原文或其他实验。规则和时间的本人留存不等于独立认证；重放一致不证明资料来自官方、不证明当时已购票，也不证明方法有效或未来收益。固定公布奖金及每个替代方案无其他同期开奖中奖收入的假设仍然适用。

该文件不能直接恢复应用数据库，也不是完整备份。隔离副本和完整恢复尚未完成的范围见[隔离恢复说明](recovery_staging.md)。
