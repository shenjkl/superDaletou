# 证据结论与个人判断

证据结论页分别展示历史回测、固定协议历史评估和前瞻实验版本的研究记录。个人判断保存选择、理由、限制和当时引用的证据摘要；保存时服务端重新核对摘要。新假设草稿关联已有判断，仍须另行固定实验协议。历史描述、本机留存与独立验证的限制保持分别显示，完成一次判断不证明方法有效或盈利。

页面与本机服务的状态无法确认时，页面提示下方是上次读取内容，判断和草稿的提交入口暂不可用；当前页面中已输入的内容保留。恢复连接后，页面重新读取回测、实验、实验版本和固定评估，展开或正在编辑的判断会重新核对其具体证据与历史判断。旧读取的迟到结果不会覆盖断连后的输入。

如果判断引用的证据摘要发生变化，输入仍保留，页面展示新证据并要求点击“确认使用当前证据”后才可保存。如果原判断或证据记录暂时无法核验，相关输入保留但不能提交。判断保存时继续进行服务端版本核验，避免查看之后证据再次变化。保存期间继续修改的输入不会被本次成功保存的响应覆盖。

个人判断和新假设现在会在发送前写入浏览器 IndexedDB 待确认日志；该日志包含恢复请求所需的输入副本，Web Locks 用于协调同源标签页。响应不确定时，页面按原键查询，可继续原请求、封止、对已封止请求关联重试，并在服务端终态核实后确认释放占用。正文不会从服务端按对象发现接口返回；若浏览器站点数据丢失，未提交正文无法从服务端恢复。输入副本会保留至确认清理或站点数据被删除，具体边界见[待确认写入说明](uncertain_writes.md)。代码接入不等于 AC76—AC79 通过；真实浏览器 IndexedDB/Web Locks、HTTP 响应丢失、并发和重启恢复仍需验收。
