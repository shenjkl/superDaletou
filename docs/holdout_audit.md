# 候选范围的本机使用记录核对

在本机服务的“历史回测”页面，选择已载入的历史快照及起止奖期，点击“核对本机使用记录”。范围按所选快照中的开奖日期顺序确定，最多 200 期；起止奖期须存在于该快照。检查使用同一个数据库只读事务，结果显示检查时点以及范围内涉及的输入期和目标期。

当前检查数据库中已留存的训练任务及模型产物、方案生成草稿、历史奖金情景与组合评估、历史回测任务及报告、纸面实验结果。运行中、失败或取消的任务同样列出：它们可能接触了数据，不代表一定已经使用。检查过程核对快照摘要和期号投影，并对支持的已保存产物核对摘要和关联配置；如果某条记录或其引用的历史无法核对，则结果标记为检查不完整，不能当作没有使用记录。

历史奖金情景的读取和使用会在计算前登记对应奖期；旧版保存的评估也按其历史来源期核对。对于未留来源引用但标有五位奖期的情景，系统保守地将该期列为可能使用，即使它实际上可能是合成情景；不能据此认定历史奖金一定被读取。新建自定义奖金需由本人声明为人工设定的假设值，或声明参考的历史奖期；后者在计算前记录期号并接受排除范围检查。本人声明不经系统独立验证，不能证明未参考其他数据。

旧版自定义奖金评估可能没有来源声明：此时无法排除与任何候选范围有关，核对会显示“有记录无法核对”，不能固定新的本机探索排除范围；已有范围及评估标为需要复核。可在“历史回测 → 核对并固定排除范围 → 旧自定义奖金来源”查看原奖金，按本人记忆追加人工假设或历史期号声明，并填写说明。补录不会修改原评估，系统也不能独立验证声明；后续可再次追加声明，所有声明保留，**任何一次声明参考的历史奖期都保守视为可能已使用**，不会被之后的人工假设声明抹除。补录后应重新核对范围；如果仍涉及已固定奖期，相关范围和报告继续显示待复核且阻止启动新评估。应用之外的使用同样无法按期追溯。

本机连接无法确认时，页面隐藏上次读取的回测任务、固定范围、来源声明和范围核对结果，原范围核对失效；当前页面的固定评估配置和正在填写的来源声明保留。连接恢复后重新读取回测、范围和来源；范围核对需要重新执行。如果正在填写的来源记录暂时查不到，输入会保留但不可提交，记录恢复后可继续编辑。未提交输入仅留在当前页面会话，刷新或关闭页面不保证保留。此处理尚不覆盖所有页面，也不等于 PRD v0.7 的未知写入结果持久核对、原子封止和全流程断连验收已完成。

即使系统没有找到相关记录，也只能说明在本次检查覆盖的本机记录中没有发现；研究者可能已经看到开奖结果，其他数据库、文件或工具中的使用也不会被发现。单独执行检查不会固定范围、证实独立性或作出方法有效的结论。

## 固定本机探索排除范围

在“历史回测”页面选择快照和起止奖期，先核对本机记录。如果未发现使用且没有无法核对的记录，可阅读限制、勾选确认，再固定为探索排除范围。固定时服务会在同一写入锁下重新核对，并拒绝与既有范围重叠；训练或回测正在运行时必须先等待结束。相同快照和起止期的重复提交返回原记录。固定后范围不可修改或取消；如需其他范围，应新增不重叠的范围。

固定范围按具体奖期生效，不因切换快照而失效。新的训练、候选生成和探索回测在使用该期作为输入或目标时被拒绝；回测还会检查目标期之前实际使用的历史窗口。以该期为来源或标注期的奖金情景也不能用于新探索评估。同步训练、生成、奖金情景及回测会在计算前持久记录拟使用奖期；范围核对会包含运行中、失败后及结束的记录，避免计算与固定并发时漏记。训练、回测的持久任务在提交和产物发布时也会检查。已固定的历史记录不被删除或改写。

普通快照明细接口对已固定范围的期号不返回开奖号码，开奖版本差异接口拒绝返回这些期号的版本详情；本机服务启动时创建范围账本，相关读取要求账本存在且内容可核验。服务发送静态数据脚本前会筛除预留期的号码行，并从静态生成历史中移除预留期、重算其摘要。静态数据包含既有回测的精确奖期清单；若与预留范围相交，服务会隐藏无法按期重算的静态汇总。数据页仍会在排除范围和连接状态核验前隐藏号码表。范围记录损坏或账本缺失时，静态数据和快照明细均失败关闭。此处理是应用读取入口的限制，不构成操作系统级访问隔离：工作区中的原始静态源文件、快照文件、数据库、其他服务或应用外工具不受覆盖；其他历史汇总也未全部按预留范围重算，不能证明用户未见过结果或所有汇总都未包含预留期。受控固定评估仍可在服务端内部读取和计算预先固定的结果。

此能力是**本机应用研究入口的探索排除**，不是完整的独立保留集：本机页面、数据库文件、其他程序或先前操作仍可能暴露开奖结果，系统不能证明研究者未见过这些数据；单独调用底层计算函数也不受应用入口约束。固定后不能使用探索回测消耗这些奖期；下述受控评估只作历史描述，完整访问隔离、独立性核验及统计推断协议仍待实现。不要将“固定范围”或“未发现本机记录”表述为独立评估已经通过。

## 固定协议的历史描述评估

固定排除范围后，在该范围下选择“配置固定评估”，一次选择需要比较的所有方法，并填写假设、统一预算、追加方式、副本数、历史窗口、种子和总运行时限。页面列出树模型与 LSTM 的固定参数和聚合规则。每个范围只能固定一份协议，固定后不能增加、替换方法或修改参数；不同方法必须使用同一目标范围、副本清单、预算和组合结构。固定前会检查总资源上限、其他排除范围和固定历史奖金情景，并留存协议摘要、情景、代码与运行环境。

固定后点击“运行固定评估”，系统在子进程中依预先固定的方法逐期重建候选和同成本随机对照；各目标期只用前面的开奖数据，同一次协议的后一期可以使用前一期已开奖数据。每对按候选减对照计算税后净收益差额；先在同一期对全部预定副本求算术平均，再对完整期等权平均。某副本或奖金情景缺失时，保留失败原因，该期不填零；页面区分完整和部分结果，可展开每个副本的税前奖金、税费、成本和净收益。无完整期时显示“暂无”。可查看已观察奖期的分布及逐期移除敏感性，口径和限制见[配对差额说明](paired_description.md)；该版本不计算跨期推断区间或自动采用结论。

每份范围只能固定一份协议；中断、超时或失败保留本次运行终态和原因，不会自动重试或更换协议。用户可显式按原协议新建重试，最多 9 次；新运行关联上一次运行，原失败记录保留。同一请求标识重发返回原尝试状态，不会启动新运行；运行中或完成后不能用新标识重复启动。运行前环境或固定奖金情景不一致时不启动。完成后若历史号码、奖金或依赖来源出现冲突，页面将当前结果标为待复核，旧报告仅供历史查看。恢复前完整性检查会核对协议、运行链、报告摘要和引用；这仍不能验证数据来源或本机时间。

这些范围和方法是在本机已有历史快照上固定的，可能早已被用户或其他工具看过。即使后续执行严格遵循固定协议，也只能标为“本机固定后的历史重建、独立性未验证”，不能宣称真实盲测、前瞻样本、策略优势或盈利。正式证据仍需解决独立选择与访问控制、真实规则适用及统计推断审核。

## 已固定但未运行的协议遇到环境更新

固定协议记录了代码和运行环境；如果系统更新后与记录不一致，原协议不能直接启动。对**从未创建过运行尝试**的待执行协议，页面提供“创建关联新版本”。本人填写原因并确认后，系统在同一事务内重新检查本机是否已有相关使用，核对当前历史奖金情景与旧协议一致，并确认旧方法配置仍受当前执行器支持。

通过后，新版本原样保留原来的方法、范围、副本、预算、种子、假设、奖金情景和时限，只记录新的执行环境及前序协议摘要。新旧版本都可查看；旧版被替代后不能启动，即使以后恢复旧环境也不例外。新版本仍属于本机历史描述，不能因为重新固定而宣称独立性已验证。相同请求重复提交返回同一版本；同一旧协议不能分叉出多个可执行版本。

如果旧协议已经启动过，即使运行失败或取消，也不能通过此入口重新标为未使用；仍须保留并按原协议处理运行记录。数据冲突、奖金情景改变、记录损坏或本机使用无法核对时，不创建新版本。当前尚未提供已运行协议在新环境中继续研究的版本流程，也不能以本机检查证明本人或外部工具未见过数据。

在“模型训练”中可以为**单次训练任务**另行声明排除范围。起止期必须同时填写，均须存在于所选快照，且按该快照的开奖顺序，训练及验证数据截止期必须早于排除起始期；系统在提交、工作进程读取以及发布前检查这一边界。声明会保存在模型配置及其生成重放包内。未声明时按原有训练方式运行。

该单任务设置不会约束其他任务、页面、文件或外部工具，也不会证明本人未查看过结果。上述本机探索排除范围须另行核对和固定；两者都不允许将回测自动标为独立评估。当前回测引擎及任务接口都只接受探索角色。
