# 方案号码生成重放包

本机服务的“方案生成 → 已保存的组合草稿”可为单个草稿下载“生成重放包”。导出前会在同一只读事务中核对配对摘要、历史快照及号码投影、相关号码冲突和生成代码；模型方法还会核对模型产物及训练输入摘要，用当前对应模型代码重新计算评分。只有重新生成的候选和随机对照均与已保存结果一致时，才生成文件。

草稿保存和使用前会检查候选/对照的子注数、成本、追加、去重、派生种子及号码池展开，核对固定请求与历史窗口摘要。当生成代码和 Python 版本与原记录一致时，系统按固定种子重放随机对照；随机、热号和冷号方法也重放候选。树模型和 LSTM 在模型代码、Python、NumPy 版本匹配时，还会核对训练输入摘要和保留集边界，用留存权重重新计算评分并重建候选号码；这一步不重新训练模型。新建前瞻登记要求候选及对照均可重放；代码或运行时不匹配的旧草稿保留供查看，但不能直接用来新登记。已经固定的历史实验不会仅因当前代码或运行时变化而被改写。

文件采用字段白名单：包括历史号码、生成所需数值参数、重放得到的两个具体组合、代码和内容摘要；树模型或 LSTM 方案还包括训练历史、训练参数、随机种子、数值权重、训练运行时版本以及本次生成的数值评分。自由文本的规则版本、日历版本替换为固定占位符，来源描述、原文、备注、请求键、会话信息、凭据和本机路径不写入文件。文件仍包含研究号码和模型权重、评分，应按个人研究资料管理。

验证需要匹配生成时的 `dlt/candidates.py` 版本及兼容的 Python 环境，在项目目录运行：

```powershell
python -m dlt.generation_replay "下载的重放包.json"
```

`matched` 表示当前代码根据包内数据重新生成的两个组合及成本一致。文件内的原始方案摘要是关联标识；单靠文件中的摘要不能认证原文件、官方来源、时间或研究结论。不同 Python 版本或代码版本可能不能重现，验证不会自动更换代码或依赖。

新版包的普通验证会用包内权重重新计算评分，但默认不重新训练，输出 `training: not_run`。如需从包内训练历史和参数重新训练模型，并逐值比对权重，可显式运行：

如果训练任务声明过排除范围，重放包也会保留这两个奖期标识；它不会因此证明数据在其他任务或工具中未被使用。

```powershell
python -m dlt.generation_replay "下载的重放包.json" --retrain
```

重训使用独立子进程，最多运行 120 秒；输出 `training: matched` 才表示重训得到的模型权重摘要一致。要求当前模型代码、Python 和 NumPy 版本与原训练一致；即便版本一致，不同数值计算环境也可能产生差异，验证会报告不一致，不自动调整结果。旧版模型包没有训练输入或权重，普通号码重放仍可用，不能重训。随机及统计方法没有模型训练，状态为 `not_applicable`。

此包不包含完整原始来源、奖金规则、结算结果、数据库任务或实验档案，不能作为完整研究导出、备份、恢复或方法有效性证明。规则及日历占位符不会参与号码抽样，但也不证明原参考资料有效。支持的生成范围为最多 2000 条历史记录、1000 注及 100000 次抽样尝试；模型训练历史最多 500 期，模型参数须满足训练任务的资源上限。旧代码版本、缺失依赖或未解决号码冲突时阻断导出。
