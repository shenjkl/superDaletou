# 历史滚动回测：当前实现与边界

通过本机浏览器服务进入“历史回测”，先载入已有本地快照，再设置奖期范围、方法、每期预算、副本数、历史窗口、种子及时间上限。支持随机、热号、冷号、树模型、LSTM 的单式组合；模型逐目标期只用之前的数据重新训练。配对随机对照使用相同结构和实际成本。完成后可展开逐期的候选和对照奖金、税、成本及净收益；取消、超时和重启不会发布成功报告。

每个目标期对全部预定副本的净收益差求算术平均；有副本失败时该期不计入均值并保留原因。跨期均值仅对完整期描述，失败或缺奖期不会视为零，不能把该均值当作有效性结论或独立检验。副本共用同一期开奖，并非独立开奖样本。页面另展示已观察差额的范围、分位及逐期移除敏感性，具体口径和限制见[配对差额说明](paired_description.md)。存在来源冲突时，既有报告保留并显示待复核，不发布当前描述统计。

当前只为本地研究覆盖的 **26014—26123 期**构造七奖级历史假设；实际可选期数还受所选快照覆盖影响，所选范围内有缺期时页面阻止运行。第 26050—26066 期如快照明确标记派奖，并含完整的基本奖与派奖奖级金额字段，可按已保存的票面分组逐张检查 18 元门槛后分别计算派奖；分组缺失、字段不全或版本冲突时该副本失败并保留原因。派奖奖项依据开奖行中的 `awardType`、`group`、`sort` 和 `stakeAmount`，并与基本奖字段分开校验。普通期仍使用公布的基本单注奖金；追加投注不猜测缺失的追加奖金。所有情景不重算新增中奖者造成的分奖或限额；每包假设无其他同期开奖中奖收入，税费按研究参数计算。快照来源和规则、税费口径没有独立认证，该计算不是真实购票/兑付记录、正式有效结算或未来奖金预测。

单个任务上限 50 期、10 副本、200 期历史窗口、100 次奖期与副本组合、每包 100 注、120 秒。当前页面固定模型参数，并在页面列明；普通回测仅支持探索角色。另可在本机探索排除范围下固定多方法协议并运行历史描述评估，失败后可显式按原协议重试；方法和目标预先固定但独立性未验证，详见[范围核对说明](holdout_audit.md)。假设检验和采用结论尚未启用。任务及完整数据保存在指定 SQLite 文件，不修改已封存的 `research/prospective/v2`。

普通回测的任务接口、存储接口和回测核心均拒绝把历史重建直接标记为 `holdout`。固定协议评估通过独立的受控入口运行并明确标记独立性未验证；两者都不能冒充未参与选择的独立评估。

页面也可对候选奖期范围核对本机已记录的历史使用情况；检查结果不构成保留集资格或独立性证明，具体口径和限制见 [范围核对说明](holdout_audit.md)。

规则参考：体彩中心对[第 26014 期起实施新规则](https://www.sporttery.cn/digitallottery/cjdlt/20260205/10052315.html)的说明；税务部门[关于彩票兑奖与适用税法有关口径的公告](https://fgk.chinatax.gov.cn/zcfgk/c102416/c5233840/content.html)规定，同一人同一期同一电脑彩票游戏的全部奖金按一次中奖收入计算。上述链接不自动认证本地文件的来源，也不取代对目标奖期规则、税费和舍入的完整核验。

失败或取消的回测任务可在任务卡片中显式按原协议和运行时限创建关联重试。新任务使用独立请求键并保留 `retry_of`；服务端核对原任务已失败或取消、回测请求完全一致，并在运行前重新检查排除范围与来源资格。原任务状态及失败原因不被覆盖。完整性检查会核验重试关联及请求一致性。
