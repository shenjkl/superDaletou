# 模型产物中的特征与预处理版本

树模型与 LSTM 的训练请求配置及训练产物都使用以下固定标识记录输入表示。训练服务会在任务受理前核对所选方法对应的版本；滚动训练配置从固定模板继承这些字段：

- `feature_schema_version: draw-window-onehot-47-v1`：每条历史记录编码为 47 维 `float64` 向量。前区 1–35 对应前 35 个位置，后区 1–12 对应后 12 个位置；号码出现时置 1，否则为 0。样本输入是按时间排序的 `window` 条历史向量序列，预测目标号码只作为训练标签，不进入该样本特征。
- 树模型使用 `preprocessing_version: window-mean-v1`：对窗口内各期 47 维向量逐位置取均值，再输入 CART 分裂。
- LSTM 使用 `preprocessing_version: raw-sequence-v1`：保留窗口顺序，将 47 维向量序列直接输入循环网络。

产物还记录算法版本、训练配置、输入行摘要、模型实现文件摘要、Python/NumPy 运行时、训练和验证目标期以及模型权重。底层训练入口、预测和模型完整性核验都会校验产物字段与嵌入配置中的算法、特征和预处理版本组合；未知或彼此不一致的版本需人工复核，不能按当前实现推理。改动算法、编码或预处理时应提升相应版本标识，并保留旧版本的明确兼容策略。

训练目前使用按期序的训练区间和验证区间；训练/参数搜索只能在固定排除范围之外读取数据。另有按范围固定单一协议的本机描述性历史评估：协议在查看报告前固定，完成后不能替换或重跑，失败只能沿原协议重试。该结构将本机探索与保留范围计算分开，但本人和外部工具仍可能看到开奖数据，独立性未经认证，不能声称已完成独立保留评估。历史快照训练标为历史重建，评分为研究分数，不是中奖概率。

每次手动训练都带有参数试验组 ID，创建新组时生成新的标识，复跑或改变参数时可复用已有标识。任务页分别保留每次运行的配置、训练/验证切分及状态，并显示其试验组 ID。

使用树模型或 LSTM 生成方案时，必须在生成请求中留存同方法、同试验组内已考虑的训练任务清单、最终选择的训练任务和选择理由；还必须填写“页面外或未登记的尝试”声明，没有此类训练时填写“无”，否则列明方法、参数及结果摘要。新记录带 `model-selection-v1` 标记；后续读取会再次强制核验比较清单中的任务属于同方法、同试验组，且快照、训练/验证边界和算法版本一致。该声明由本人提供并与选择记录一同不可变保存。服务端校验本机所选任务与模型产物相符；查看已保存草稿时可以复核理由、训练任务清单及外部尝试声明。旧版未标记格式继续按其原规则读取。系统无法自动发现页面外训练，也不能核验本人声明的完整性或真实性；该记录不证明选择过程独立，也不替代独立保留评估。

旧版未记录试验组 ID 的训练任务不能据此视为属于同一个组。新草稿选择此类模型时，比较清单只允许包含所选任务自身；需要比较多次训练时，应重新用共同试验组 ID 运行并记录每次尝试。历史上已保存的草稿仍按其原请求读取和核验。

新选择清单还要求参与比较的尝试使用相同快照、历史起始期、训练/验证边界、排除与滚动目标声明，以及算法、特征和预处理版本。窗口、随机种子和模型参数可以在组内变化作为试验变量；不一致的输入来源或验证区间不能放在同一清单里。历史草稿仍按其原有规则核验。

已保存模型草稿的选择决定另存为按序追加的不可变历史。初始决定从原草稿选择清单导入历史；每次新增决定都保留所选尝试、完整比较清单、理由和页面外尝试声明，绑定到同一草稿及其模型方法，并携带内容摘要。历史页展示每次决策的最终尝试、比较清单、理由和页面外尝试声明，并明确声明未经核验。新增写入先严格持久化到浏览器 IndexedDB，再由服务端在单一事务中保存历史条目和待确认写入回执；网络中断可查询、封止并关联同内容重试。新增历史只记录后续决策，不会改写已生成草稿实际使用的模型产物或候选号码；更换模型产物须另存新草稿。历史不覆盖原草稿请求，也不表示模型或选择过程经过独立审计。

失败或取消的训练任务可在任务卡片中显式按原配置创建关联重试。页面使用新的待确认请求键，保留原任务键和状态；服务端只接受失败/取消的原任务、逐字段相同的训练请求，并在实际提交时重新核验窗口、来源、滚动目标与排除范围。新任务记录 `retry_of`，完整性检查核对其原任务终态及配置一致性。重试不会覆盖原失败原因；若需调整参数，应作为试验组中的新训练尝试另行提交，不冒称为重试。

模型训练表单提供可选的参数网格搜索。用户为树模型或 LSTM 填入各参数候选值后，系统生成笛卡尔积（每个参数最多 8 个值、每组最多 64 次），所有任务固定相同快照、数据切分、试验组 ID 和随机种子。完整尝试清单及独立请求键在首次训练提交前写入严格持久 IndexedDB，再串行启动每个训练任务；失败、取消和明确拒绝逐项保留，状态未知时暂停并沿用原请求键核验。重开训练页可继续未完成清单。用户可停止搜索：停止标志先持久化，活动子任务沿用任务取消日志，后续未提交尝试标为跳过；取消状态不明时计划暂停，恢复后继续核验而不会启动下一项。清除浏览器站点数据会删除尚未提交尝试的本机计划；已经创建的子任务仍保存在服务端任务表。此搜索只属探索，既不使用也不认证独立保留集。
