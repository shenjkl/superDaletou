# 配对差额的观察分布与敏感性

历史回测、固定协议历史描述评估及多奖期纸面实验，均以同一开奖期的候选税后净收益减去随机对照税后净收益为配对差额。一期内先对全部预定副本求算术平均，再以一个奖期作为一个观察值；副本不当作独立开奖期。缺少任一预定副本、奖期尚未登记或结果待复核时，该期不进入当前计算，不填零；页面显示计划、已计入和缺口数量。

对当前可计入的奖期展示：

- 候选高于、等于或低于对照的奖期数，以及实际观察到的最小、最大差额。
- P25、P50 和 P75：将各期平均配对差额排序，用最近秩法取对应值；偶数期的 P50 不是两中间数的平均。
- 逐一移除一个完整奖期，分别计算剩余奖期均值，再展示最小至最大的范围。只有一期时无法计算；这个范围用于观察均值对单期的敏感性。
- 单期最大绝对差额占全部有效期绝对差额之和的比例。绝对差额之和为零时不适用；存在并列时按预定奖期顺序显示第一期。

金额先按精确分数计算，再按界面显示精度四舍五入。上述数值描述的是**已观察到的数据**，不是总体均值的置信区间、未来收益范围、显著性检验或采用建议。数据缺口和部分结果可能影响方向及幅度；未观察到的罕见大奖也不会出现在样本分布中。不能仅因为多数期差额为正或某个范围不跨零就宣称方法有效。分布范围和方差都可能受极端值影响；参见 [NIST 对离散程度和极端值的说明](https://itl.nist.gov/div898/handbook/eda/section3/eda356.htm)。

历史结果的描述统计在读取时从原报告计算；系统先复核期号、副本顺序、各配对差额与期内及跨期均值，不修改原报告或其摘要。已知来源冲突或数值不一致的报告标为待复核，不展示新的当前分布。前瞻汇总从同一数据库读取快照中提取当前有效结果；确认资料更正后、重算成功之前，受影响奖期从当前统计撤出，原历史记录保留。

这些描述不建立独立保留集资格。只有推断方法、显著性、多重比较、样本量及审核依据按 PRD 固定并通过核验后，才能启用相应的统计推断；当前没有自动推断或采用结论。
