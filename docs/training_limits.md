# 训练资源与参数限额

当前训练执行器使用 `dlt/training_limits.py` 中的不可变 `DEFAULT_TRAINING_LIMITS`，任务提交、底层训练和滚动训练共用该配置。限额对象在创建时检查边界形状、数值类型、有限值和上下界顺序。服务端通过需本机同源会话的 `/api/training-limits` 返回 `training-limits-v1` schema、限额和算法/特征/预处理版本；页面先核对响应 schema 与字段结构，再用同一响应生成输入边界和版本化任务配置。接口读取失败或结构不兼容时训练表单不开放。初始边界为：

| 项目 | 当前范围 |
|---|---:|
| 单任务运行时限 | 1–120 秒 |
| 模型历史窗口 | 1–120 期 |
| 训练历史行数 | 3–500 期 |
| 树最大深度 | 0–5 |
| 树最少叶样本 | 1–100 |
| LSTM 隐藏维度 | 1–32 |
| LSTM 训练轮数 | 1–10 |
| LSTM 学习率 | 0.0001–1.0 |

这些值是当前原型的保守默认上限，不是性能标定后的生产配置；超出范围的请求会被拒绝。服务端验证才是执行约束。部署前仍需按目标硬件、并发策略和响应时间完成性能标定；当前没有运行基准测试。
