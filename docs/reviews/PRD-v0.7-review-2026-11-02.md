## 覆盖和一致性复核

| 维度 | 核查结果 |
|---|---|
| 目标、角色、范围 | 延续个人本机、方案比较和真实多模型研究；未增加购票、多人或外网能力。Q1—Q5 未改变。 |
| 流程与状态 | 沿用数据、训练、生成、回测、登记、计算、结论流程；新增未确认写入的核对、封止和受控重试路径。 |
| 规则与异常 | 明确业务错误与连接不确定的区别；旧响应不能覆盖新状态；封止与提交竞争只能有一个结果。仍以具体来源、截止和权限规则为先决条件。 |
| 数据、权限与隐私 | 待确认索引仅保存核对需要的最小标识与摘要，不保存凭据/令牌；不改变 R43/R49 研究导出与备份边界。 |
| 指标与证据 | 本轮未修改税后净收益配对差额、奖期统计、独立评估或统计协议门槛；连接恢复不能把旧证据冒充已复核。 |
| 页面、验收 | 会话内编辑与已保存记录分别表述；AC73—AC79 覆盖断连、业务错误、迟到读取、未知写入、刷新与封止竞争。 |
