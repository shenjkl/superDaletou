## 覆盖与验收复核

| 维度 | 复核结论 |
|---|---|
| 目标、用户、范围 | 单人本机、真实多模型研究、成本收益比较、保留失败试验的范围明确；不包括购票和收益承诺。 |
| 流程和状态 | 草稿、固定、登记、结算、更正、关闭和新假设均有入口及边界；关闭后已固定包仍处理。 |
| 权限和数据 | 仅本机访问，后台写操作有来源/会话校验；历史版本不覆盖，具体本机访问保护按T06交付。 |
| 核心口径 | 税前、税后、成本、ROI、配对差额、同奖期副本和不参与基准已分开；缺失不填零。 |
| 异常和恢复 | 缺数据、迟到、依赖更正、冲突、重复、服务停止、部分恢复有确定处理；计划不在关机期间执行。 |
| 页面和通知 | 页面入口与页内交互约束明确；应用内通知保留，外部推送不在首版。初始原型是历史依据，不能作为当前完成证明。 |
| 验收 | R01—R45 与 AC01—AC67 保留可追踪关系；本次新增 AC56—AC67 覆盖时点、税费、关闭、新假设、证据变更、后台和恢复边界。 |

三项关键正反向例子：

1. **历史时点：**给定事后抓取且无可用时间证明的历史数据，当选择严格时点重放时拒绝；选择历史重建时可运行并标识限制（AC56）。
2. **个人判断：**给定用户看到的结果被来源更正影响，当保存旧页面中的判断时要求重新加载；历史判断及其证据快照保留（AC60）。
3. **恢复：**给定候选库存在损坏引用，当执行恢复核验时不得覆盖原库或启用候选计划，并显示原因（AC63）。
