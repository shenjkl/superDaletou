## 2. 需求背景

### 2.1 业务背景

用户希望理解大乐透购买方案的成本、收益分布和证据，判断是否参与，同时持续探索新方法。用户已选择个人使用、本机浏览器运行、首版包含多模型研究；本轮进一步确认首版需要定时更新、核验通过后自动计算纸面实验收益且异常时暂停；关闭浏览器后本机后台继续执行，电脑关机/休眠时不执行，恢复后补查。主要研究指标采用税后净收益配对差额。

### 2.2 当前问题

- 分散的玩法分析、方法训练和实验记录难以关联到同一个可复现的具体方案。
- 中奖、整期盈利、平均奖金和预测证据容易被混用；单次大奖和历史最优容易误导判断。
- 同预算但不同结构的对照不能直接证明选号能力；具体号码包也不能挪用其他布局的概率结果。
- 当前原型真实训练、新回测、包级评估、持久化及调度服务尚未接入；页面任务状态不等于产生真实模型或研究证据。

### 2.3 需求依据与现状

2026-10-29 静态基线：官方历史200期；历史探索106个常规奖期；既有第26124期实验9种策略、500副本、4500组合包，有效结算0期。均为版本化研究事实，不代表实时数据。开源参考以本地来源清单中的修订版本为准，不把项目名称当作有效性证明，不预设可直接复用其代码或许可证。

当前八页原型已经具备通用情景计算、随机/热号/冷号候选及匹配对照、会话草稿。未具备真实树模型/LSTM训练、具体候选包收益评估、新滚动回测、持久化实验、定时更新。正式首版须补齐这些建设项。

## 3. 产品目标

| 目标ID | 目标 | 判定依据 |
|---|---|---|
| G01 | 方法和生成结果可追溯、可复现 | 数据、规则、代码、参数、产物、种子、子注和运行标识完整 |
| G02 | 用户能够比较参与成本与收益分布 | 数值口径一致、保留不参与基准、显示不确定性和适用情景 |
| G03 | 真实模型可进入独立评估 | 树模型及LSTM具有可核验产物，滚动评估隔离未来信息 |
| G04 | 前瞻实验具有完整记录链 | 预登记、截止检查、版本保护、开奖后计算和异常留存 |
| G05 | 没有优势也能形成有用结论 | 保留全部试验及否定结果，支持新假设，明确暂无采用依据 |

盈利、优于随机、未来可重复属于研究结论，不能作为软件必须达成的保证。工程指标与研究指标分别统计；不虚构业务增长、命中率或盈利率目标。

## 4. 非目标

首版不包含购票、代购、支付、兑付、提现、自动投注、资金托管或收益承诺；不建设多租户、多人协作、社交跟单、商业订阅、外网访问、多种彩票、Transformer及大规模分布式搜索。

仅本机浏览器访问；不开放局域网或云端入口。首版包含定时更新的产品能力，本轮编写PRD不部署服务、不创建真实定时任务、不发送通知。外部认证和可信时间戳方案尚未选定，不宣称本地哈希具有第三方时间证明效力。

## 7. 核心业务对象

以下对象均归属唯一研究者；标识不可复用。状态为本版业务合同，详细流转见第10节；数据库和接口命名可不同，但不得改变业务含义。

| 对象 | 创建条件与定义 | 关键标识/关系 | 状态/失效 |
|---|---|---|---|
| 数据快照 | 来源读取成功后建立的不可变输入 | snapshot_id、来源、抓取/可用时间、内容摘要 | 待核验/可用/隔离；更正产生新快照 |
| 规则版本 | 按适用期号确定的奖金、税费、派奖和日历口径 | rule_id、有效期范围、依据 | 待核验/生效/被替代；禁止覆盖历史引用 |
| 方法版本 | 算法、特征、预处理和构建规则固定后建立 | method_version、代码摘要 | 草稿/可用/停用 |
| 训练任务 | 配置校验通过并持久化后建立 | task_id、训练数据、切分、资源 | 排队/运行/取消中/取消/失败/完成 |
| 模型产物 | 真实训练输出且完整性核验后建立 | artifact_id、权重、预处理、来源任务 | 待核验/就绪/无效；不是任务状态的同义词 |
| 生成任务 | 方法可执行、目标/预算有效时建立 | generation_id、输入快照、种子 | 排队/运行/失败/取消/完成 |
| 组合包/配对 | 候选和对照通过合法性及成本校验后一起发布 | packet_id、pair_id、全部子注、版本摘要 | 有效/来源撤回标记；历史内容不可编辑 |
| 评估运行 | 指定包或完整方法、情景、协议后建立 | evaluation_id、包摘要、协议、范围 | 排队/运行/失败/取消/完成/待复核 |
| 实验版本 | 研究者保存假设、指标、观察范围后建立 | experiment_id、version、候选/对照关联 | 草稿/待观察/进行中/已关闭；版本固定后不可改内容 |
| 奖期计算记录 | 官方结果、奖金与适用规则均可核验时建立 | settlement_id、实验/目标期/包/结果版本 | 待数据/阻断/计算中/完成/待更正 |
| 证据结论 | 引用已核验评估并写明协议后建立 | evidence_id、指标、样本、限制 | 待评估/描述性结果/待复核/结论记录 |
| 更新计划/运行 | 用户保存有效计划或触发一次更新时建立 | schedule_id、run_id、下次执行时间 | 计划启用/暂停；运行成功/失败/跳过 |

一个方法可关联多次训练；产物只引用确定的训练任务及数据。一个生成任务产出候选和对照包；一个包可用于多次不同情景评估。一个实验版本关联多个奖期、配对及结果，不能将多副本等同独立奖期。

## 8. 业务流程

### 8.1 主流程

```mermaid
flowchart LR
 A[更新并核验数据/规则] --> B[配置方法与训练]
 B --> C[核验产物或规则方法]
 C --> D[生成候选和匹配对照]
 D --> E[实际组合包评估与独立滚动回测]
 E --> F[保存并固定实验版本]
 F --> G[截止前生成/登记奖期组合]
 G --> H[获取官方开奖与奖金]
 H --> I[校验并计算纸面实验收益]
 I --> J[汇总证据与参与判断]
 J --> B
```

### 8.2 分支流程

- 随机及统计方法跳过训练；模型缺产物则阻止生成，不回退随机号码冒充模型。
- 可先生成探索候选，再独立回测；探索结果不得回填为未见结果的前瞻证据。
- 手工方法草稿固定协议后，须在截止前关联具体奖期组合包，单有草稿不足以构成有效样本。
- 未发现优势可关闭本版假设并创建新版本；保留原全部结果。

### 8.3 异常流程

来源不可用、奖金缺失、规则未核验、截止不明或已过、引用版本冲突时，停止相应有效生成/结算，保留原因与可恢复入口；不填零，不凭本机时间伪造前瞻资格。来源恢复后按幂等条件重试，不改写原记录。

## 9. 功能需求

本节规则按“条件—动作—结果”描述；执行状态、启用前必填项与阻断行为为本版需求合同，具体算法、资源和协议参数通过第9.9/17.2节配置与核验，未配置不得启用；每个模块的角色为研究者，自动任务的内部权限受第5/13节约束。

### 9.1 M01 研究概览

**目标/入口：**登录或打开本机应用的默认页面；展示事实进展和下一操作。

| 规则ID | 条件 | 动作与结果 |
|---|---|---|
| R01 | 存在可用数据和实验 | 展示数据截止、更新状态、目标奖期、有效奖期数、异常及任务入口；每项可追溯来源 |
| R02 | 无模型产物或无有效结算 | 显示暂无结果及对应入口，不绘制虚构表现曲线；任务完成不增加有效奖期 |

**交互：**研究日程、待办和证据摘要分组；待观察按目标日历排序，任务按创建时间倒序，同时间按ID排序。更新失败保留上次成功时间。无数据提供导入/更新入口。

**验收：**AC01、AC02。来源读取失败不清空已有历史成果。

### 9.2 M02 数据与规则

**目标/入口：**数据与规则；任务创建前必须能解析可用快照、期号日历与规则。

| 规则ID | 条件 | 动作与结果 |
|---|---|---|
| R03 | 更新返回数据 | 按9.9节分别核验号码输入资格与收益计算资格；期号、号码、来源非法则隔离，奖金暂缺不阻断不依赖奖金的号码研究，收益计算继续等待 |
| R04 | 与已存记录不一致 | 保存新旧来源及差异，不静默覆盖；标记受影响评估/结算待复核 |
| R05 | 用户启用定时更新 | 由本机后台服务保存和执行计划；关闭浏览器不停止更新，关机/休眠不执行，恢复后补查；定时与手动使用同一校验流程，重复运行幂等 |
| R06 | 当前期号跨年、改期或规则变更 | 以已核验日历/规则解析，不能仅以期号数字+1确定未来目标；无法解析则阻断并提示 |
| R07 | 税费、派奖、浮动奖或限额口径未核验 | 不将硬编码历史口径作为生产有效规则；相关结算/结论标为不可执行 |

**交互：**来源、更新时间、覆盖范围、隔离原因、差异对照、规则适用期号、定时计划页内编辑。首次计划暂停，必须选择计划再启用；关闭浏览器后继续运行、关机/休眠时不执行及恢复后补查已确认，具体频率/重试/漏跑合并见T01。来源失败显示原因与重试；原快照仍可查看。

**验收：**AC03—AC07、AC28、AC37。历史快照与实际可用时间都要留存，防止使用开奖后才知道的数据预测过去。

**后台执行边界：**浏览器只作为本机操作界面；关闭或重新打开浏览器不重复创建执行器。后台服务的安装、启动方式和是否开机自启由T01技术设计明确，当前确认不包含自动唤醒电脑。补查先更新并核验官方数据，再对已提前登记且条件齐备的记录计算收益；重入和重复补查遵守R31幂等要求。

### 9.3 M03 模型训练

**目标/入口：**模型训练；首版真实支持树模型和LSTM，随机/热号/冷号不要求训练。

| 规则ID | 条件 | 动作与结果 |
|---|---|---|
| R08 | 用户提交训练配置 | 校验窗口、目标、数据可用性、特征/预处理版本、切分和资源；通过后持久化任务并执行，失败则保留字段错误 |
| R09 | 训练/验证/保留范围存在未来信息 | 拒绝任务；标准化、特征选择及调参同样不得读取保留期或目标数据 |
| R10 | 执行器报告训练结束 | 核验权重、预处理、代码及配置摘要；只有产物就绪才能供生成使用；日志成功但缺权重记为失败/产物无效 |
| R11 | 用户取消或运行崩溃 | 进入取消中/失败，不发布不完整产物；保留日志和失败原因；重试建立新任务并关联原任务 |

**交互：**方法说明行内展开；配置页内编辑，任务列表显示状态、模型、窗口、产物和运行时间；默认按创建时间倒序。运行更新不覆盖另一份正在编辑的配置。完成页进入生成或回测；生成入口仍核验产物。

**验收：**AC08—AC11。模型细选、资源上限、随机非确定性容差和停止规则见T02/T03，不伪造默认准确率。

### 9.4 M04 方案生成

**目标/入口：**方案生成、方法说明、训练完成；前置为可用方法/产物、完整历史和可解析目标期。

| 规则ID | 条件 | 动作与结果 |
|---|---|---|
| R12 | 用户生成候选 | 固定方法、窗口、预算、结构、追加、种子与数据；校验子注合法性，按明确策略去重，记录实际成本和余额 |
| R13 | 模型无可用权重/历史不足/预算不足 | 阻止生成，显示原因；不得悄悄替换方法或生成空包 |
| R14 | 候选生成完成 | 同一生成运行下原子发布候选及随机对照；成本、子注数、结构、追加与重复策略一致，种子按配对协议预定且不筛选 |
| R15 | 当前选择的输入或其依赖内容发生变化 | 按依赖摘要失效当前展示结果并禁止以新配置登记旧包；新增无关奖期不使固定包失效；来源更正按R38标记引用待复核，不覆盖旧包 |
| R16 | 需要重放或重复提交 | 相同输入及确定性执行环境可重放；重复请求返回同一运行及其终态，失败/取消也不自动新建；主动重试使用新请求标识并关联retry_of。幂等请求键采用请求标识，保存配置/来源摘要；同键不同摘要拒绝，重放查询与主动新建运行分开 |

**交互：**配置、候选/对照成本表、全部号码、生成依据、证据状态和登记入口；默认不做采用排名。当前窗口60/120、预算2—360及固定胆拖为原型边界；正式限额见T03，不能未经评估无限扩展。候选无须训练评分，模型评分不直接显示中奖概率。

**验收：**AC12—AC16。任何覆盖数量均注明不代表中奖概率。

### 9.5 M05 方案比较与实际组合包评估

**目标/入口：**方案比较或生成结果；区分通用结构/布局情景与实际组合包分析。

| 规则ID | 条件 | 动作与结果 |
|---|---|---|
| R17 | 发起具体包评估 | 输入实际完整子注、重复/追加、包摘要与情景版本；不得只按注数套用另一个随机包的概率 |
| R18 | 评估完成 | 保存计算方式、种子/样本数、区间、时间、规则和输入摘要；精确、随机模拟及历史描述分别标明 |
| R19 | 预算、结构、包或奖金情景改变 | 隐藏不再适用的结果并提示重算；取消/失败不将旧结果改名成本次结果 |
| R20 | 方案实际投入不同 | 列出成本和余额但不直接作收益排名；保留不参与基准，不将负收益较优者自动推荐购买 |
| R21 | 使用历史公布奖金情景 | 写明适用期和固定情景假设，是否处理假设新增中奖者分奖/限额必须可见；不表达为下一期奖金预测 |

**数值口径：**成本C为组合包全部子注实际投入；税前奖金G为同包合计；按适用规则计算税费T；净收益N=G−T−C。中任意奖为G>0；回本为N≥0；整期盈利为N>0。理论平均奖金（税前）为ΣP(结果)×G(结果)，包含零奖及罕见大奖；不是净收益或当期通常到手金额。

有限模拟未出现头奖不能报告精确零概率；区间只表达对应模拟误差，不能冒充未来收益区间。能够解析求得的均值/一等奖覆盖应使用相应数学计算；具体区间算法、精确计算限额见T03/T04。

**交互：**一个方案一行，概率条与数值合并；显示区间、成本、方法、理论平均奖金（税前）、一等奖概率。该列悬停提示“包含未中奖及罕见大奖”。唯一重算入口与样本次数集中显示；手机表内滚动。无结果显示简短状态，不放大图标或重复按钮。

**验收：**AC17—AC20。对照和候选的模拟宜共享开奖结果以作配对，协议选择须固定，不将推断收益优势写进表格排序。

**目标/入口：**证据结论、报告入口；前置为可追溯评估或实验结果。

**配置合同：**

- 更新计划必填：计划表达、时区、来源集合、重试次数上限（非负整数）、重试等待规则（正值/有界）、运行超时（正值）、启用状态。首装无已启用计划；用户保存并启用后才运行。重试耗尽记本次失败，后续正常计划仍可执行；用户暂停计划后不再派发新运行。暂停与运行取消分别操作。关闭浏览器不改变计划状态；关机/休眠恢复遵循R42。具体频率无预置隐含值。
- 方法执行配置必填：算法及代码版本、特征/预处理输入输出结构、输出评分到组合的构建规则、输入窗口、训练/验证/保留集合、重训策略、种子及环境、资源上限和超时。随机方法无训练字段；模型必须真实产物。以已保存产物重放生成要求子注一致；重新训练允许产生不同权重，但须作为新运行/产物，不复用旧ID。
- 限额配置必填：预算/子注/窗口/并发/时限的可用上界及来源。正整数上界、预算以所选价格规则允许的精度表示；超限在提交前拒绝。执行器不得发布超过配置上限或不完整的结果。没有限额配置则相关任务不可提交，技术团队选择数值不需要改变用户已定业务范围。
- 评估协议必填：模式（描述/推断）、主要指标、观察范围、完整副本清单、配对映射、聚合器标识和数学定义、排除规则、重训/选择规则。描述模式输出点估计和清楚标注的不确定性，不产生自动采用结论；推断模式还须具备检验/区间方法、显著性/多重比较与样本量规则、审核依据，缺项不得启用。模拟区间与跨期推断协议分开。
- 规则和时间合同必填：规则依据、适用期、价格/奖金/税费/舍入及派奖口径、内部截止、已核验官方截止/日历、实际时间证明等级与协议要求。只记录本地时间时，仅能满足声明接受本地留存的协议，仍显示“本地时间留存，未经独立认证”；要求更高证明等级的协议缺少相应凭证时阻断。收益计算资格与时间证据等级分别展示。

**数据资格：**快照逐记录保留`numbers_usable`、`settlement_ready`及原因。号码研究可使用前者为真的记录；使用奖金/销售额等特征时须另外核验对应字段。只有官方开奖号码、奖金、适用规则及实验完整性均齐备才可计算收益。部分缺字段不删除已可用号码，也不以零填缺失奖金。

**指标合同：**每包净收益Ni=Gi−Ti−Ci；每对D(t,r)=N候选(t,r)−N对照(t,r)。每期统计D(t)=A({D(t,r)})，A必须由固定协议给出且对两侧一致；例如算术平均可作为配置选择，但本PRD不自动替用户选择聚合器。跨期均值为有效奖期D(t)之和/有效奖期数；没有有效奖期显示不适用，不显示0。部分期缺失时展示缺失范围，不悄悄改变预登记总体或发布协议不允许的结论。

同一规则对候选和对照使用相同金额精度及舍入；金额计算用精确十进制/最小单位，不使用显示后数值回算。固定浮动奖情景不等于实际新增购票分奖模拟，正式有效结算必须显示对应规则的适用假设。

**本机访问合同：**只接受loopback来源的请求；本机其他网页不能通过跨站请求触发训练、启停计划、固定实验或计算写入。实现必须具有本机操作会话和写操作来源/请求校验，不选定具体认证框架；备份/导出不能带出凭据。能力的实现方式可技术选型，访问/写入边界不能省略。

## 10. 状态流转

以下为本版业务状态集合；不要求界面暴露所有内部状态词，但必须能表达其差异。

| 对象 | 原状态 → 条件 → 新状态 | 可操作与终态规则 |
|---|---|---|
| 数据快照 | 待核验→通过→可用；待核验→异常→隔离 | 隔离可追加处置后建立新版本，原内容不改 |
| 任务 | 排队→开始→运行；运行→取消请求→取消中→已取消 | 取消中不得发布产物；完成/取消/失败为该次运行终态 |
| 任务 | 运行→完整核验通过→完成；运行→错误/中断→失败 | 重试创建新运行，保留原ID与原因 |
| 模型产物 | 待核验→完整/来源通过→就绪；核验失败→无效 | 就绪后发现来源撤回可标记无效，引用结果待复核 |
| 当前结果 | 输入一致→可用；任何依赖变更→不再适用 | UI不显示为当前结果，历史记录仍存在 |
| 实验 | 草稿→固定协议→待观察→首个结果→进行中→用户关闭→已关闭 | 固定后改协议开新版本；关闭不等于方法有效 |
| 奖期结果 | 等待开奖→官方结果出现→待数据→核验通过→计算中→完成 | 缺奖金/规则/截止异常→阻断；恢复后新运行，不丢原因 |
| 更正结果 | 已完成→官方或规则更正→待更正→复算→新版完成 | 原结果保留，汇总标明当前采用版本 |
| 证据 | 待评估→结果齐备→描述性结果→协议复核→结论记录 | 任务完成不触发证据升级；新证据可形成新结论版本 |
| 计划 | 暂停→用户保存启用→启用→用户暂停→暂停 | 一次运行成功/失败不默默改变计划；连续失败处理见T01 |

取消与完成竞争以持久化终态判定：同一运行只接受一个终态；若已完成，再次取消显示已完成，不删产物；若取消先被接受，迟到结果不得发布为成功。实验固定与过期检查必须在同一提交事务内再次校验。

## 12. 消息与通知

首版确认包含定时更新，但外部消息渠道未定义，本PRD不包含邮件、短信、聊天推送或实际创建通知。

| 消息 | 接收/渠道 | 触发与去重 | 跳转与结束 |
|---|---|---|---|
| 任务结果 | 研究者/应用内 | 每运行终态一次，按task_id去重 | 对应日志/产物；查看后可标已读，审计不删 |
| 更新失败/规则缺失 | 研究者/应用内 | 按run_id和原因记录；不能因通知失败丢运行结果 | 数据核验/重试；恢复另记新事件 |
| 实验收益阻断 | 研究者/应用内 | 对应实验/奖期/输入版本及原因 | 查看缺失字段或截止异常；处理后新运行 |
| 记录更正待复核 | 研究者/应用内 | 官方结果或来源更正影响引用 | 查看差异与新旧结果；复核仍保留历史 |

关闭浏览器后，本机后台继续执行并持久化更新/收益计算结果；再次打开浏览器读取同一份记录。关机或休眠期间不执行，恢复后补查。提示失败不回滚已成功业务记录。应用内消息排序、保留与清理策略为建议，待技术设计细化。

## 13. 权限与数据范围

所有页面仅处理本人空间；正式服务只绑定本机访问，拒绝外网/局域网入口。执行器不接受绕过截止、伪造来源或覆盖封存的指令。凭据和源数据导出范围明确分离。

草稿可以编辑；固定版本、已发布包和已完成结算不能直接编辑/删除以改变既有证据。允许追加备注、关闭或创建更正版本。停用方法/撤回产物后保留历史引用，新生成阻断。记录清理/归档策略待定义，默认不删除审计所依赖内容。

无访问或写入权限时拒绝动作并返回明确原因，已有记录不丢失；后端再次校验状态和引用，不能信任前端按钮可用性。导出建议提供结构化记录和报告，只包含本人可见内容，是否加密及备份机制见T06。

## 14. 异常与边界情况

| 场景 | 系统动作 | 用户反馈/恢复 |
|---|---|---|
| 无数据或历史不足 | 拒绝依赖该输入的训练/生成，保留配置 | 显示所需/可用数量和更新入口 |
| 号码非法、重复期号、来源冲突 | 隔离异常，不静默修正覆盖 | 查看差异并创建核验后的新版本 |
| 预算不足一注/结构 | 拒绝生成空包或超预算包 | 显示最低结构成本/调整建议 |
| 缺权重或预处理版本 | 不执行模型推理 | 显示缺失项及训练入口 |
| 输入变更但旧任务迟到 | 根据输入/运行标识判定，不显示为当前结果 | 提示结果属于旧版本，可查看历史 |
| 反复点击或并发提交 | 幂等接收；版本冲突返回重载提示 | 不双写包、不重复封存或计入收益 |
| 运行中取消/资源耗尽 | 原子处理终态，失败产物不发布 | 显示原因，可新建重试 |
| 未开奖或奖金未公布 | 等待数据，不填零结算 | 标明缺少官方结果/奖金 |
| 规则未知、派奖/改期 | 按预登记规则处理或阻断/排除并记原因 | 不事后择优决定是否纳入 |
| 截止不明、迟到或本机时钟异常 | 不认证合格前瞻 | 显示时间来源与限制，保留为异常记录 |
| 官方数据事后更正 | 标记引用结果待复核，新版重算 | 新旧值与影响可追溯 |
| 磁盘不可写/容量不足 | 未成功提交不报告已保存，保护旧记录 | 明确失败和恢复路径 |
| 关机、休眠、错过计划 | 不在关机/休眠期间执行，恢复后补查；只对已有合格记录自动补算，不补造截止前组合 | 显示漏跑、补查及阻断原因 |
| 协议或算法变化 | 新方法/实验版本 | 原结果继续使用原协议解释 |

### 15.2 事件与研究审计
